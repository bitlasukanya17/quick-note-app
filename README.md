# Quick Note Application 📝🐾

A colorful and user-friendly Quick Note Application built using HTML, CSS, Python Flask, and SQLite database.

##  Features

- Add and save notes
- Store notes using SQLite database
- Display saved notes dynamically
- Responsive colorful UI
- Flask backend integration
- Beginner-friendly project

##  Technologies Used

- HTML
- CSS
- Python
- Flask
- SQLite
